# 学习 App

这是一套**学习专用软件**。浏览器能打开，也可以装到手机主屏，网页和 App 是同一套页面。

把讲义阅读、自己整理题目、编程练习放在一起，方便长期用，不是备考站点。

代码分层、模块怎么接，见 [`项目结构.md`](./项目结构.md)。

## 里面有什么

- **题库整理**：自己建分类、录入题目、测验和导出
- **计算机基础 / 前端学习**：树形讲义，可阅读、测验、导出
- **编程题练习**：按题目补全 TypeScript 并跑测试
- **项目介绍**：说明当前首页开着的模块
- 管理员另有**项目管理**（源码查阅与下载）

安装、登录和设置在首页右上角。首页显示哪些卡片，可在设置「菜单管理」里开关。

## 开发

```bash
npm install
npm run dev:full
```

`dev:full` 会同时起 Vite 前端和本地登录 / AI 代理。只起页面可用 `npm run dev`（默认端口 **5174**）。

```bash
npm run build
```

类型检查：`npm run type-check`。

## 部署

静态前端 + Cloudflare Pages Functions（`functions/`）。讲义和编程题正文走云端存储，不写进公开仓库。环境变量与密钥用 `scripts/sync-*.mjs` / `push-cf-*.mjs`，不要把密钥写进前端。
